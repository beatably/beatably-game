# Beatably graphics library

Reusable promotional artwork based on Beatably's current landing page and supplied brand assets.

## Masters

- Landscape, square and portrait key art without text
- Original relaxed expression plus excited, wink and curious variants

## Recommended exports

- `beatably-landscape-logo-3840x2160.png`: wide hero/press image
- `beatably-landscape-logo-1920x1080.jpg`: general 16:9 directory image
- `beatably-square-logo-3000x3000.png`: square directory cover
- `beatably-square-no-text-3000x3000.jpg`: high-resolution no-text submission image
- `beatably-indiex-square-500x500-no-text.jpg`: Indie X gameplay-art slot (no text/logo)
- `beatably-portrait-logo-2160x2700.png`: vertical press/social image
- `beatably-portrait-curious-logo-1080x1350.jpg`: vertical expression variant

Use no-text exports where a platform forbids text or logos in the main image. Generated key art is promotional artwork and should not be presented as a literal gameplay screenshot.
